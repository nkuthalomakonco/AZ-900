# AZ-900

Microsoft Certified: Azure Fundamentals (AZ-900)

The Microsoft Certified: Azure Fundamentals (AZ-900) is an entry-level cloud certification exam offered by Microsoft. 
It validates foundational knowledge of Microsoft Azure services, concepts, pricing, and security. 
The certification is widely recognized as a starting point for learners and professionals exploring cloud computing or planning advanced Azure specializations.

The AZ-900 exam tests general understanding of cloud principles and core Azure services rather than hands-on implementation. Major content domains include:

Cloud concepts (IaaS, PaaS, SaaS, shared responsibility model)

Core Azure architecture and resources

Security, privacy, compliance, and trust

Azure pricing, service-level agreements, and lifecycle management
